# House Price Predictor

An end-to-end machine learning project: generate a dataset, train a scikit-learn regression pipeline, and serve real-time predictions through an interactive Streamlit app.

---

## What it does

Enter a property's details (bedrooms, bathrooms, kitchens, floor area, lawn, city vs. out-of-city) and the app returns an estimated price instantly from a trained model.

## ML pipeline

| Step | Detail |
|---|---|
| Data | 1,000 synthetic properties (`generate_dataset.py`), price built from known feature effects plus Gaussian noise (σ = 20,000) |
| Features | `bedrooms`, `bathrooms`, `kitchens`, `area_sqft` (numeric) · `lawn`, `location_type` (categorical) |
| Preprocessing | `ColumnTransformer` with one-hot encoding for categoricals, passthrough for numerics |
| Model | `RandomForestRegressor` (100 trees) inside a scikit-learn `Pipeline` |
| Split | 80/20 train/test, `random_state=42` |
| Serving | Pipeline saved with `joblib`, loaded by the Streamlit app |

## Results (held-out test set, 200 properties)

| Model | R² | MAE | RMSE |
|---|---|---|---|
| Random Forest (deployed) | 0.913 | 20,419 | 25,564 |
| Linear Regression (baseline) | 0.942 | 16,711 | 20,820 |

**Takeaway:** because the synthetic price is generated by a linear formula, the linear baseline wins, and its RMSE (~20.8k) sits right at the noise floor (σ = 20k), meaning it has captured essentially all of the learnable signal. The Random Forest is the more flexible choice for real-world housing data, where relationships are non-linear, but on this dataset the simpler model is better. The next step is to retrain on a real dataset (e.g. UK Land Registry price-paid data) and compare models with cross-validation.

## Project structure

```
generate_dataset.py    Creates house_prices.csv
train_model.py         Builds and trains the pipeline, saves house_price_model.pkl
app.py                 Streamlit app for live predictions
house_price_model.pkl  Trained model
```

## Run locally

```bash
git clone https://github.com/Alok-Yadav-21/house-price-predictor.git
cd house-price-predictor
pip install -r requirements.txt

python generate_dataset.py   # optional: regenerate data
python train_model.py        # optional: retrain the model
streamlit run app.py
```
